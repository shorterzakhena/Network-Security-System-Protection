# Network-Security-System-Protection

**Project Overview**

This lab combines IT networking and cybersecurity fundamentals.

The objective is to examine a computer's network configuration, test connectivity, investigate DNS information, and review Windows Firewall settings.

This project demonstrates how network administration and security work together to help protect computer systems.

**Objectives**

- Examine network configurations.

- Understand basic DNS functionality.

- Test network connectivity.

- Review Windows Firewall settings.

- Understand how firewalls help protect computers.

- Document basic network security findings.

**Tools & Technologies**

1. Windows 10 or Windows 11

2. Command Prompt

3. PowerShell

4. Windows Defender Firewall

**Skills Demonstrated**

- Network configuration

- DNS investigation

- Network connectivity testing

- PowerShell

- Windows Firewall

- Network security fundamentals

- Technical documentation
